# Palworld Breeding Calculator
A Next.js fan-made Palworld breeding planner and IV estimate tool.

## Run locally
```bash
npm install
npm run dev
```

## Important data note
This first release intentionally does not fabricate breeding outcomes or claim a complete Pal database. The pairing planner records parent/target selections. Exact offspring lookup should be connected only after importing and validating a complete, versioned breeding dataset against current game mechanics.

## Deploy
Connected to Vercel through GitHub. Pushes to the production branch trigger deployments.

Unofficial fan project; not affiliated with Pocketpair.
